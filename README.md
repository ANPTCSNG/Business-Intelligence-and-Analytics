# Business-Intelligence-and-Analytics
Classroom final Project
Introduction
In today’s highly competitive market, leveraging data analytics is essential for sustaining business growth and maintaining a competitive advantage. This report presents a comprehensive data visualization and analytical study of a restaurant’s sales performance using Microsoft Power BI. The primary objective of this analysis is to address operational inefficiencies by transforming raw transactional data into meaningful and interactive visual insights.
A relevant Restaurant Sales dataset was sourced and processed using Power Query within Power BI. The data was cleaned and transformed to ensure accuracy and consistency before analysis. The study focuses on examining transaction-level data to uncover patterns in customer purchasing behavior, identify peak dining hours, evaluate menu item profitability, and assess overall revenue performance.
